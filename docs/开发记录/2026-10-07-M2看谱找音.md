## 1. 交付内容

### 1.1 练习模块接口（技术方案 §8 的落地）

```
practice/
├─ base.py           Question / RenderSpec / QuestionContext / PracticeModule 协议
├─ registry.py       注册表：@register_module 一行注册，主程序零改动
├─ session.py        会话控制器（三种模式、判定接入、统计、得分）
└─ pitch_find/       模块一：出题、渲染描述、判定配置
```

**可扩展性的具体体现**：首页的模块卡片由注册表自动生成，新增练习只需新增一个包并注册，
不需要改动首页、练习屏或会话控制器。

### 1.2 会话控制器（纯逻辑，无 Qt 依赖）

| 能力 | 说明 |
|---|---|
| 三种模式 | 固定时长（5/10/15/30/45 分钟）、固定数量（10/20/30/50/100 题）、自由练习 |
| 判定接入 | 复用 `PitchClassJudge`，判定配置来自模块 + 设置（三档稳定时长、三种试音模式） |
| 统计 | 题量、首次正确率、最终正确率、错答次数、跳过、超时、平均反应时间、最高连击、最弱训练项 |
| 得分 | 需求 FR-830：基础 100 × 难度系数 × 时间奖励 × 连击加成（回炉题减半，可关闭） |
| 控制 | 暂停/继续（暂停时冻结计时并停麦克风）、跳过、随时结束 |
| 可测试性 | 时钟可注入，整个会话流程用合成 `PitchEvent` 完整测试 |

### 1.3 界面

- **六线谱控件** `NotationTab`：6 条线 + 品格数字、弦号、粗弦画粗、答对/答错配色、
  答错时高亮标准位置、可选音名提示、来源标签（复习/强化/回炉）；字号随控件高度自适应
- **练习屏** `PracticePage`：顶栏（进度/正确率/连击/剩余/得分）+ 六线谱主区 +
  实时音高表 + 反馈文字 + 快捷键（空格暂停、S 跳过、Esc 结束）
- **会话设置对话框**：难度、模式、时长/题量、是否含升降号、音名提示、得分开关
- **会话小结论框**：本次成绩 + 最弱训练项 + "再来一次"

## 2. 本轮抓出的两个真 bug

### 2.1 残留音把下一题"秒判错"（严重）

**现象**：会话测试中，第 3 题在 `t=2.00` 就被判错，`correct_first` 只有 2/3。

**根因**：上一题答对后，**琴弦还在响**。这些"残留帧"被喂给下一题的判定器，
如果连续两题音名相同，残留音正好"符合"上一题的答案，于是把新题判错。

**为什么严重**：吉他一个音可以响好几秒，**比默认 2 秒宽容期还长**。这不是测试造出来的
极端情况，而是真实使用中必然发生的——用户答对后新题刚出现，旧音还在响，就会被判错。

**修复**：判定器引入"武装（arming）"机制：

| 触发条件 | 行为 |
|---|---|
| 配置里指定 `ignore_pitch_class`（上一题的音名） | 初始为未武装：该音名的帧不参与判定 |
| 检测到**新拨弦**（`is_onset`） | 武装并清空窗口 |
| 检测到**不同音名** | 武装（说明用户弹了别的音） |
| 静音超过 `silence_reset_ms`（默认 300ms） | 解除忽略（说明旧音已衰减） |
| 判错之后 | 重新变为未武装，必须新拨弦才再判 —— 否则同一根还在响的弦会被反复判错 |

最后一条同时修掉了另一个问题：**一次弹错被记成很多次错**。

### 2.2 练习屏的相对导入层级写错

`ui/pages/practice.py` 里写成了 `from ..core...`（应为 `from ...core...`），
模块根本导入不了。单元测试没覆盖到界面，是**打包自检里的练习屏冒烟**抓出来的——
这也说明冒烟测试值得纳入构建流程。

### 4.1 数据持久化的设计

`SessionRecorder` 是一个挂在 `PracticeSession` 上的**会话事件观察者**，
把 `started / correct / wrong / timeout / skipped / finished` 写成
`sessions` 与 `attempts` 两行表记录。

两个刻意的设计：

1. **观察者抛异常不得中断练习**：数据库故障不能把用户的训练打断。
   异常被捕获并记在 `recorder.error` 里（有测试覆盖）。
2. 它跑在 UI 线程而不是音频线程，因此逐条写入即可；SQLite 开 WAL 不影响采集。

`items`（训练项熟练度）**不在 M2 更新**——那是 M3 记忆曲线的职责，
M2 只在 `attempts` 里记下原始事实。

**演示方式**（换好麦克风后）：
`dist\JitaTrainer\JitaTrainer.exe` → 首页点「看谱找音」→ 选难度与模式 → 开始练习。
练习数据会写入 `data\jitatrainer.db` 的 `sessions` / `attempts` 表。
