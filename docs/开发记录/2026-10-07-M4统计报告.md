## 2. 本轮修掉的一个隐蔽 bug：时间戳口径不一致

写统计时发现：**答题时间存的是"本地裸时间"，而会话与训练项存的是 UTC**。

```python
# 修改前
def _now_iso() -> str:
    return datetime.now().isoformat(timespec="seconds")   # 本地、无时区
# 而 sessions/items 用
def utc_now_iso() -> str:
    return datetime.now(timezone.utc)...replace("+00:00", "Z")   # UTC
```

**后果**：按天聚合时，下午 8 点之后（UTC+8）的答题会被算到**前一天**；
时段对比、逐日曲线的数据都会错位，而且在单机使用时很难被发现——
"昨天明明练了，今天怎么没记上"。

**修复**：

1. 答题时间改为统一的 UTC；
2. 统计层**取原始行、在 Python 里按本地日期分桶**（SQLite 做时区转换很别扭），
   并把"今天是哪天"做成可注入参数，便于测试跨时区边界。
