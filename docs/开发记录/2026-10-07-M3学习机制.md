### 1.1 记忆曲线（需求 FR-610）

训练项 = **音名 × 把位区间**；间隔序列 `0 / 1 / 3 / 7 / 16 / 35 / 75 / 160` 天。

| 事件 | 间隔索引 | 下次到期 |
|---|---|---|
| 首次即弹对 | +1（封顶最后一档） | now + 间隔[新索引] |
| 答错后改正 | 归零 | 当天 |
| 答错 | 归零 | 当天 |
| 跳过 / 超时 | 归零 | 当天（遗忘权重 0.5） |
| 带音名提示答对 | 不变 | 不变（不计入熟练度） |

另有错误率与反应时间的指数滑动平均（α=0.3），供易错加权使用。

### 1.2 易错加权（技术方案 §9.3）

```
w = (1 + 2.0 × error_rate)
  × (1 + 1.5 × max(0, (2500 − avg_rt) / 2500))
  × (0.5 + 0.5 × min(1, 距上次练习天数 / 7))
```

### 1.3 出题调度（需求 FR-710）

每 10 题一个配额窗口：**到期复习 ≤4、薄弱强化 ≤3、新题 ≥3**；
到期项按逾期天数优先；薄弱项按加权随机；某类无可用项时配额顺延给下一类。

首次使用无历史数据 → **全为新题**（需求 §14-3）。

### 1.4 错题回炉（需求 FR-720）

答错/跳过/超时的题隔 **5–8 题**（随机）重现；**连续 2 次答对**才移出跟踪；
回炉题不占配额，但总量不超过会话题量的 **30%**。

### 1.5 难度进阶建议（需求 FR-620）

取该难度最近 3 次会话：正确率 ≥90%、平均反应 ≤2.5s、累计答题 ≥60 题 →
首页显示"建议解锁下一难度：L2（0–5 品）"。**只给建议，不自动切换**。

## 2. 本轮抓出的三个真缺陷

这三个都是"调度器行为不符合直觉"的问题，只有把调度器跑成序列才能发现。

### 2.1 训练项会连续出现

调试输出显示同一个音（pc=3）连续出了 4 题：

```
题 0 new  pc=3   题 1 review pc=3   题 2 weak pc=3   题 3 weak pc=3
```

**修复**：加"最近 2 题不重复"的候选筛选。这条筛选**可以回退**（宁可重复也不能没题可出）。

### 2.2 回炉机制形同虚设

失败的题被排入回炉队列（5–8 题后重现），但它同时是"到期项"（SRS 把它设成当天到期），
于是**在回炉到点之前就被普通通道重新抽走了**——回炉队列还没轮到就被清理，机制等于不存在。

**修复**：给已排期回炉的题加**绝对锁**——在回炉重现之前，它不走到期/薄弱/新题任何通道。

**关键区分**（我第一版修错了）：

| 筛选 | 是否可回退 | 理由 |
|---|---|---|
| 等待回炉的题 | **绝对排除** | 否则回炉机制失效 |
| 刚刚出过的题 | 可回退 | 宁可重复，也不能没题可出 |

第一版把两者合成一个"候选为空就退回原列表"的过滤器，结果单候选场景下回炉锁被绕过。

### 2.3 全部题目都在等回炉时死锁

连续全部答错时，所有题都进了回炉队列且受 30% 比例限制而延迟，
于是"排除等待回炉"后候选为空 → `IndexError`。

**修复**：这种极端情况下让回炉锁让位（取最久没练的题），保证永远有题可出。
