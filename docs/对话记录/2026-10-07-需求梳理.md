## 0. 用户初始需求（原话要点）

> 做一个吉他练习小程序，可运行在 Windows 桌面，Python 编写，绿色安装。主要功能是提供各种练习吉他的方法，并且可以不断扩展。
> 第一个练习功能：屏幕上随机输出一个音符，使用者弹出这个音，程序通过麦克风收到声音后判断是否准确，然后输出下一个音符，以此反复。
> 具体要求：
> 1. 屏幕输出音符时要以吉他通用琴谱标记来表示
> 2. 随机输出音符范围可以由用户指定（按难度来分）
> 3. 记录用户易错的音符，后续输出时加强训练
> 4. 采用基于记忆曲线的方式周期性复习
> 5. 每次练习可以由用户指定时间（固定时间、固定音符数量、自由练习直到用户结束）
>
> 并明确要求：先理解需求，然后通过提问的方式进一步理清需求，形成需求文档，**审核通过后再进入下一步工作**。

## 0.1 关于「头脑风暴」与「grillme」技能

用户要求使用「头脑风暴技能」与「grillme 技能」。经核实，本机技能库（会话技能清单 + 磁盘搜索）中**不存在**这两个技能。已向用户说明，并采用等价方法执行：

- **头脑风暴部分** → 先发散完整产品形态、隐含假设、可扩展模块地图与风险清单；
- **grillme 部分** → 以「抬杠的产品负责人」视角，逐轮逼问未定义边界，直到每个决策点闭合。

## 0.2 环境问题与修复（过程记录）

启动阶段遇到工作区 `D:\JitaTrainer` 的 Windows 文件权限问题：DSH 无法为该目录授予写权限（`SetNamedSecurityInfoW failed (Win32 5): grantWrite`），所有命令均无法执行。

- 处理：使用 `diagnose-windows-sandbox-acl` 技能提供的诊断+修复脚本，为当前登录用户补上该目录的完全控制权限；变更前已自动备份原权限，回滚脚本位于 `D:\dsh-acl-recovery`。
- 结果：验证通过，工作区恢复可用（脚本输出 `nextAction: verify_original_confined_operation`，重试成功）。

## 1. 第一轮提问：产品定位与基础技术选型

**AI 复述的理解（供用户纠正）**：Windows 免安装绿色版吉他练习器；随机出题 → 弹奏 → 麦克风判音 → 出下一题；谱面用通用吉他标记；难度分级；易错强化 + 记忆曲线；三种会话模式；练习模块可插拔。

## 2. 第二轮提问：交互边界与技术细节

**AI 指出的关键矛盾**：六线谱的每一格必然落在「某条弦 + 某个品」上，等于指定了精确位置；但麦克风只能听出音高，**永远无法判断弹的是哪根弦**。因此「按把位出题」与「判定不限弦」之间必须显式调和——这直接决定数据结构。

| # | 问题 | 用户的决定 |
|---|---|---|
| 1 | 六线谱标出弦与品、但麦克风只能听音高，怎么调和？ | **谱面给标准位置，判定只认音高**（弹同音高的其他位置照样算对） |
| 2 | 记忆曲线里的一个「训练项」是什么粒度？ | **音名 × 把位区间**（同一个 B 在 1-3 品与 5-7 品算两个独立技能点） |
| 3 | 真实练琴时会先试几个音找位置，程序怎么处理？ | **三种模式都提供，用户自己选**（宽容期 / 严格 / 不判错） |
| 4 | 弹错时的反馈方式？ | **提示错误并停留，直到弹对** |
| 5 | 一次练习中需要哪些控制能力？ | **全选**：暂停/继续、随时手动结束、跳过本题（计入薄弱项）、无声音超时自动跳过、实时进度显示、键盘快捷键 |
| 6 | 需要记录和展示哪些数据？ | **全选**：正确率、每题反应时间（毫秒级）、错音排行/热力图、逐日练习时长与曲线、时段对比（周/月）、导出 CSV |
| 7 | 调音器与题目范围支持到哪种调弦程度？ | **目前只实现标准调弦 EADGBE**；备注：*"后续扩展功能时可以扩展到 2、3、4"* |
| 8 | 「可以不断扩展」具体想要哪种扩展方式？ | **内置模块注册表**（新增练习 = 新增一个 Python 模块并注册） |
| 9 | 界面形态与体验要点？ | **深色主题、练习屏全屏大字模式、首页（档案+模块+统计+设置）、弹奏时实时音高指示（带偏差音分）**；追加：*"中英文双语可选界面"* |
| 10 | 麦克风与识别参数怎么配置？ | **首次运行向导：选设备 + 测环境噪声 + 试弹校准** |

## 3. 第三轮提问：学习机制、默认参数与工程约束

**AI 指出的关键组合**：判定只认音高，而复习粒度是「音名 × 把位区间」——这意味着跨难度复习策略必须明确定义，否则数据会被污染。

| # | 问题 | 用户的决定 |
|---|---|---|
| 1 | 难度级别怎么进阶？ | **程序根据正确率给「建议解锁下一级」提示**（需用户确认后切换，不自动切换） |
| 2 | 到期复习题允许超出当前选定的把位范围吗？ | **不跨界**：只复习当前范围内的到期项 |
| 3 | 新题、到期复习题、本次错题回炉怎么配比？ | **到期复习 → 薄弱项 → 新题 自动配比；错题隔 5–8 题回炉** |
| 4 | 判定与会话的默认参数是否采用 AI 建议值？ | **采用建议默认值**（容差 ±25 音分可调 ±10–±50；稳定 300ms 可调 150–600；宽容期 2s；无声音 8s 算不会；时长档 5/10/15/30/45 默认 15；题量档 10/20/30/50/100 默认 30） |
| 5 | 绿色版的具体形态？ | **单文件夹绿色版，数据存程序目录** |
| 6 | 中英双语要做到什么程度？ | **界面文案全部中英双语可切** |
| 7 | 要不要游戏化激励？ | **加连击与本次得分（可选关闭）**，不做成就体系 |
| 8 | 未来一年想扩展哪些模块？ | **音阶与调式练习、和弦与和弦转换、节奏与节拍训练**（本次不实现，仅登记优先级） |
| 9 | 第三方库与联网限制？ | **允许安装必要第三方库（pip 需要联网一次），运行时完全离线** |
| 10 | 程序叫什么？ | **JitaTrainer / 吉他训练器** |
