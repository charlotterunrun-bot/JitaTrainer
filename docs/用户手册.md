# JitaTrainer 用户手册

**吉他训练器 · 绿色版**（Windows 单文件夹，免安装、免管理员权限）

---

## 1. 这是什么

JitaTrainer 用麦克风听你弹吉他，判断你弹的音**对不对**，并把练错的地方记下来，
按记忆曲线在合适的时间再拿出来给你练。

当前版本包含：

| 功能 | 说明 |
|---|---|
| **看谱找音** | 屏幕出现一个六线谱音符，你在吉他上弹出它；弹对了自动出下一题，弹错了会提示并停在本题 |
| **调音器** | 指针式显示六根弦的音准偏差（音分） |
| **校准向导** | 选择麦克风、测量环境噪声、试弹校准起音门限 |
| **记忆曲线** | 练过的音按 0/1/3/7/16/35/75/160 天安排复习；练错的音会更快再出现 |
| **统计报告** | 正确率曲线、练习时长、错音热力图，可导出 CSV |

**完全离线**：程序不联网、不注册、不上传任何数据。

---

## 2. 快速上手

1. 把 `JitaTrainer` 整个文件夹解压到任意位置（**中文路径、带空格路径都可以**）。
2. 双击 `JitaTrainer.exe`。**不需要管理员权限**，不会写注册表。
3. 首次启动会弹出**校准向导**，按提示选麦克风、安静环境测噪声、弹几个音。
4. 建议先打开**调音器**把吉他调准——音准偏差太大会影响判定。
5. 回到首页点「**看谱找音**」→ 选难度和模式 → 开始练习。

**摆放建议**：麦克风放在**吉他音孔前方 20–40 cm**、略偏向琴桥。
离音孔太近会轰隆失真，太远则低音弦收不到。

> **重要**：请**不要**用蓝牙音箱/蓝牙耳机的麦克风。实测这类设备的麦克风在
> 普通音乐场景下会主动做降噪与静音，吉他这种持续音会被当成噪声处理掉
> （开发期实测：150 秒里只有 9 秒有信号，其余是数字静音）。
> 用**有线麦克风**或**笔记本内置麦克风阵列**。

## 3. 练习界面

```
┌──────────────────────────────────────────────┐
│ 进度 3/30   正确率 92%   连击 5   剩余 12:34  │   ← 顶栏
├──────────────────────────────────────────────┤
│                                              │
│  1 ────────────────────────────────────      │
│  2 ────────────────────────────────────      │
│  3 ────────────────────────────────────      │
│  4 ────────────  [ 5 ]  ───────────────      │   ← 六线谱：数字是品
│  5 ────────────────────────────────────      │
│  6 ────────────────────────────────────      │
│                                    复习      │   ← 题目来源标签
├──────────────────────────────────────────────┤
│  实时音高表（指针 + 音分）                    │
├──────────────────────────────────────────────┤
│  正确！  420 ms        空格 暂停  S 跳过  Esc 结束 │
└──────────────────────────────────────────────┘
```

**快捷键**

| 键 | 作用 |
|---|---|
| `空格` | 暂停 / 继续（暂停时会关闭麦克风） |
| `S` | 跳过本题（计入薄弱项） |
| `Esc` | 结束本次练习并看小结 |
| `F11` | 全屏（谱面更大） |

**题目角落的标签**告诉你这道题为什么出现：

- 无标签 = 新题
- `复习` = 到期复习（记忆曲线安排的）
- `强化` = 你在这类音上错得比较多，加强练习
- `回炉` = 刚才答错的题，隔几题再问你一次

## 4. 三种练习模式

| 模式 | 说明 | 适合 |
|---|---|---|
| **固定数量** | 10 / 20 / 30 / 50 / 100 题 | 每天定量完成 |
| **固定时长** | 5 / 10 / 15 / 30 / 45 分钟 | 有固定练习时间 |
| **自由练习** | 不限量，自己按 `Esc` 结束 | 想起来就练 |

难度等级决定题目出现在指板的哪个范围：

| 等级 | 名称 | 范围 |
|---|---|---|
| L1 | 初学者 | 0–3 品（含空弦） |
| L2 | 入门 | 0–5 品 |
| L3 | 进阶 | 0–7 品 |
| L4 | 全指板 | 0–12 品 |

## 5. 判定能做什么、不能做什么

> 本程序通过麦克风判断**音高**，**无法**知道你按的是哪根弦、哪个品。
> 因此当题目标注"第 5 弦第 2 品"时，你在别的弦上弹出**同样的音**同样算通过。
> 标注位置的作用是帮你建立指板地图，而不是限制你必须按在那里。

具体来说：

| 能判断 | 不能判断 |
|---|---|
| 你弹的音名对不对（C、D、E…） | 你按的是第几弦第几品 |
| 音准偏了多少音分 | 你的指法、手型、拨弦方式 |
| 反应快慢、是否犹豫 | 音色、力度是否好听 |
| 同一音名的不同八度**不区分**（E2 和 E3 都算 E） | 节奏是否准确 |

**同一答对即算对**：判定只看音名，不看八度。练习时弹高八度或低八度都算通过。

## 6. 学习机制（为什么会有"回炉题"）

- 每个训练项 = **音名 × 把位区间**（例如 "E 音在 L2 区间"）。
- 答对 → 下次复习时间往后推（1 → 3 → 7 → 16 → 35 → 75 → 160 天）。
- 答错 / 跳过 / 超时 → 回到"当天"，并排进**回炉队列**，隔 5~8 题再问你。
- 同一题**连续两次答对**才移出回炉队列。
- 每 10 题里大致有 4 题复习、3 题强化、3 题新题；某类没有可出的题时，配额顺延。

开启「显示音名提示」后，谱面会直接显示音名。**带提示答对不计入熟练度**——
这只是帮你认谱，不会让程序误以为你已经掌握了。

**难度建议**：当你在某难度最近 3 次练习都达到「正确率 ≥ 90%、平均反应 ≤ 2.5 秒、
累计 ≥ 60 题」时，首页会提示可以进入下一难度。程序**只建议，不自动切换**。

## 7. 统计报告

首页点「统计报告」：

- **KPI**：累计题量、正确率、平均反应时间、累计练习时长
- **时段对比**：本段（7/30/90 天）与前一段的题量、正确率对比，带涨跌颜色
- **正确率曲线**：逐日正确率
- **练习时长**：逐日练习分钟数
- **错音热力图**：12 个音名 × 各级别，颜色越红错得越多，格子里的数字是错误次数
- **最需加强**：错误率最高的几个训练项

**导出 CSV**：导出两个文件——答题明细与逐日汇总。用 UTF-8 BOM 编码，
Excel 双击打开不会乱码。

## 8. 数据与备份

**数据位置**：程序目录下的 `data\` 文件夹。**把整个文件夹拷走就是完整备份。**

```
JitaTrainer\
├─ JitaTrainer.exe
├─ data\
│  ├─ jitatrainer.db      ← 全部练习数据
│  ├─ backups\            ← 自动备份（保留最近 10 份）
│  └─ exports\            ← CSV / 档案导出的默认位置
└─ logs\
   └─ jitatrainer.log     ← 出问题时的排查依据
```

**自动备份**：每次启动、每次练习结束、以及清空数据前，各做一次备份，
保留最近 10 份。备份用的是 SQLite 在线备份，即使程序正在写入也能拿到一致快照。

**菜单「数据」里可以**：

| 项目 | 说明 |
|---|---|
| 打开数据目录 | 在文件管理器里打开 `data\` |
| 立即备份 | 手动做一次备份 |
| 导出档案… | 导出单个档案为 JSON（含训练项、会话、答题明细、设置） |
| 导入档案… | 从 JSON 导入：可**新建档案**或**覆盖当前档案**（导入前自动备份） |
| 清空本档案统计 | 删除本档案的练习记录（二次确认，清空前自动备份） |

**换电脑**：把整个文件夹拷过去，或者只导出档案 JSON 再导入。

## 9. 常见问题

**麦克风没反应 / 一直没有反应**

1. 打开「校准向导」重新选麦克风，确认电平条会随弹奏跳动。
2. 检查 Windows 隐私设置里是否允许桌面应用使用麦克风。
3. 如果是蓝牙耳机/音箱，换有线设备（见 §2 的重要提示）。

**低音弦（6 弦 E、5 弦 A）判定不灵**

笔记本内置麦克风对 60–150 Hz 响应较差，低音弦电平可能比高音弦低约 30 dB。
建议：

- 麦克风靠近音孔一些；
- 在「校准向导」里把起音门限调低一点；
- 或者换一个频响更好的有线麦克风。

**明明弹对了却判错**

- 先确认吉他调准了（用调音器）。整体偏低几十音分就可能落在容差之外。
- 检查「稳定时长」设置：选「快速」更容易被拨弦瞬态干扰，选「稳健」更宽容。
- 环境噪声大时，先跑一遍校准向导重测噪声门限。

**弹错了却算我对**

判定只看音名。如果你弹的音和答案**音名相同、只是八度不同**，程序会算对——
这是设计如此（见 §5）。

**程序起不来**

- 换个路径再试（中文、带空格的路径都是支持的）。
- 看 `logs\jitatrainer.log` 的最后几行。
- 在命令行运行 `JitaTrainer.exe --selftest`，它会打印环境自检结果，
  报告同时写到 `logs\selftest.json`。

**会联网吗？会收集数据吗？**

不会。程序完全离线运行，不联网、不注册、不上传任何数据。
唯一的网络行为是开发期的 git 同步，与运行的程序无关。
