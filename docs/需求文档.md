## 0. 本文档的来源与边界

本文档由三轮提问收敛而成，所有决策均可追溯到明确答复。三类内容在文中分别标注：

- **【已定】** 用户已明确选择，实现时不得擅自更改。
- **【建议】** 由我提出的默认值或方案，用户已整体认可，但实现中如遇冲突可再议。
- **【待确认】** 尚未拍板的小项，列在 §14，不阻塞开发启动。

> 说明：用户要求使用的「头脑风暴（brainstorming）」「grillme」两个技能在本机技能库中不存在（已核实技能清单与磁盘）。本文档的提问环节采用了等价方法：先发散产品形态与风险，再以"抬杠的产品负责人"视角逐轮逼问未定义边界。

## 1. 产品定位

### 1.1 一句话定义

一个**常驻 Windows 桌面的吉他指板训练器**：屏幕用六线谱给出一个音符，用户在吉他上弹出来，程序通过麦克风听音判断对错，答对即出下一题，并按记忆曲线安排复习与易错强化，让"看谱 → 找到音 → 弹出来"变成肌肉与听觉的本能反应。

### 1.2 目标用户

- 主要用户：**自己**（成人业余吉他学习者），Windows 单机使用，外接 USB 麦克风练习木吉他。
- 次级场景：家中多人共用一台电脑，各自有独立档案与进度。

### 1.3 核心价值

1. **闭环即时**：不需要老师、不需要音箱，弹错立刻知道。
2. **有的放矢**：系统记住你哪个音、哪个把位不熟，反复喂给你。
3. **可长期坚持**：跨天复习调度 + 轻量正向反馈（连击/得分）。
4. **可扩展**：练习模块是插件，未来加音阶、和弦、节奏模块时，音频层/调度层/数据层/UI 框架全部复用。

### 1.4 明确的非目标（本次不做）

- ❌ 判定你弹的是哪根弦 / 哪个品（纯麦克风物理上做不到，见 §3.3 技术边界）。
- ❌ 和弦、节奏、音阶、听音、视奏模块（已列入路线图 §12，本次不实现）。
- ❌ 降半音调弦、变调夹、开放调弦（架构预留，本次只做标准调弦 EADGBE）。
- ❌ MIDI 输入、云同步、手机端、多人联网对战、成就体系。
- ❌ 音频录音留档与回放。

## 2. 术语表

| 术语 | 含义 |
|---|---|
| 音名 / pitch class | C、C#、D…B 共 12 个，**不含八度**。E2 与 E4 视为同一个音名 E。 |
| 把位区间 / level | 按品格跨度划分的难度级别：0–3品、0–5品、0–7品、0–12品（含空弦 0 品）。 |
| 训练项 / item | 记忆曲线的最小单位，**键 = 音名 × 把位区间**（如 `B @ L2`）。 |
| 题目 / question | 一次出题，含目标音名 + 谱面展示位置 + 所属训练项。 |
| 标准位置 | 谱面上标出的"第 X 弦第 Y 品"，**仅作展示与提示，不参与判定**。 |
| 宽容期 | 出题后允许用户试音（找位置）而不判错的时长。 |
| 稳定时长 | 检测到的音高需持续多久才被视为"用户给出的答案"。 |
| 到期项 | 记忆曲线中 `due_at <= now` 的训练项。 |
| 回炉 | 本次会话中答错的题，隔若干题后再次出现。 |

## 3. 核心设定与关键技术边界

### 3.1 判定原则【已定】

**只认音名（pitch class）**：题目为 B，用户弹第 5 弦第 2 品、第 3 弦第 7 品、第 2 弦空弦，**全部算对**。

- 不判八度、不判弦、不判品。
- 谱面标出的位置是"标准答案展示"，帮助建立指板地图，但不作为判对依据。
- 后续版本可选细化到"音高+八度"乃至"指定弦位"（见 §12 路线图），架构须为此预留（判定策略可插拔）。

### 3.2 谱面呈现【已定】

- 本次**只做六线谱 TAB**：6 条线 + 品格数字，标注弦与品。
- 不画五线谱（后续可增加）。
- **默认隐藏音名字母**，避免用户直接读字母而绕过指板思考；设置中可开启"显示音名提示"（开启后本题不计入统计，标记为"带提示"）。
- 谱面区必须足够大：全屏模式下，六线谱与品格数字在 1 米外清晰可读。

### 3.3 技术边界（必须写进产品认知）

**麦克风只能得到"你弹了什么音高"，得不到"你按在哪里"。** 因此：

- 任何"必须按指定弦/品"的需求，在当前音频方案下**无法自动验证**，只能靠展示与自觉。
- 音频识别的两个主要失效模式：**八度误判**（把 E2 听成 E3）与**环境噪声误触发**。
  - 缓解 1：音高检测采用 YIN + 谐波校验（检查检测频率的 2f/3f 谐波能量关系），降低八度误判。
  - 缓解 2：首次运行的环境噪声测量 + 可调起音门限（gate）+ 稳定时长确认。
  - 缓解 3：**低音区（E2=82.41Hz）检测窗需 ≥2048 采样点**，判定延迟会比高音区略长，界面需以"收音中"状态明示，不假装瞬时。

### 5.2 扩展方式【已定】

**内置模块注册表**（不做外部热插拔）：

```python
# 新增练习 = 新增一个包 + 一行注册
@register_module
class PitchFindModule(PracticeModule):
    id = "pitch_find"
    name = {"zh_CN": "看谱找音", "en_US": "Note Finding"}
    ...
```

模块接口须包含：

- `generate_question(ctx) -> Question`：依据调度层给出的训练项生成题目。
- `render_spec(question) -> RenderSpec`：声明谱面如何画（本次为 TAB；未来和弦图/节奏谱由各自模块声明）。
- `judge(question, pitch_event) -> JudgeResult`：判定策略可替换（音名 / 音名+八度 / 指定位置）。
- `stats_fields() -> [...]`：本模块特有的统计维度。
- `settings_schema() -> [...]`：本模块特有的设置项（自动渲染设置面板）。

**架构为未来预留、本期不实现**：判定策略插件化（对应"后续细化为音高+八度/指定弦位"）、调弦预设抽象（标准/降半音/变调夹/开放调弦统一为一个 `Tuning` 对象，本期只实例化标准调弦）。

## 6. 功能需求

### FR-100 档案管理【已定：多档案】

| 编号 | 需求 |
|---|---|
| FR-101 | 支持创建多个学习者档案（名称、头像色块、创建时间），启动时默认进入上次使用的档案 |
| FR-102 | 支持重命名档案、删除档案（二次确认 + 自动备份） |
| FR-103 | 每个档案拥有独立数据：训练项熟练度、到期复习计划、会话历史、统计、得分 |
| FR-104 | 设置分两级：**全局设置**（音频设备、语言、主题、快捷键）对所有档案生效；**档案设置**（把位范围、容差、会话默认模式、提示开关）按档案保存 |
| FR-105 | 支持档案数据导出/导入（单个 JSON 文件，含全部训练项与会话历史） |

### FR-200 首页与导航【已定】

**首页四区**：档案选择 / 练习模块入口 / 统计入口 / 设置入口。

- 显示当前档案名、今日是否还有到期复习项（如"今日待复习 12 项"）。
- 模块入口卡片显示：模块名、简述、上次练习时间与本次正确率。
- 若有"建议解锁下一难度"，在对应模块卡片上显示提示徽标（见 FR-620）。

### FR-300 首次运行向导【已定】

首次启动（或更换设备后）引导三步：

| 步骤 | 内容 |
|---|---|
| 1. 选择输入设备 | 列出所有输入设备，显示默认设备标记；可即时试听电平 |
| 2. 测量环境噪声 | 静默 3 秒，统计噪声地板，建议起音门限（可手动微调） |
| 3. 试弹校准 | 提示依次弹响 6 根空弦（E A D G B E），逐弦给出识别结果与音分偏差，同时完成**音高校准**（记录整体偏差偏移量） |

向导可跳过，设置页可随时重新运行。向导结果写入全局设置。

### FR-400 调音器（可选入口）【已定：需要，但不强制】

- 标准调弦 EADGBE（本期只此一种；`Tuning` 对象已为多调弦预留）。
- 实时显示：当前音名、目标音名、音分偏差、指针式偏差表、高低提示。
- 指针式偏差：±50 音分满刻度，误差 ≤ ±5 音分时显示"准"（绿色）。
- 可从首页进入，也可在练习前提示"琴准了吗？"，但不阻塞练习。

### FR-500 模块一：看谱找音（Note Finding）【核心】

#### FR-510 出题规则

| 编号 | 需求 |
|---|---|
| FR-511 | 从当前把位区间（L1: 0–3品 / L2: 0–5品 / L3: 0–7品 / L4: 0–12品）内随机选一个合法指板位置，取其音名作为目标 |
| FR-512 | 每个把位区间的合法位置由指板映射表预计算（弦 × 品 → MIDI 音高），不使用硬编码 |
| FR-513 | 题目音集默认**仅自然音**（C D E F G A B）；设置中可开启"包含升降号"（升号优先显示，如 A# 不写 Bb） |
| FR-514 | 避免与上一题完全相同的位置；同一音名不连续出 3 次以上 |
| FR-515 | 出题逻辑必须由调度层驱动（见 FR-700），不允许纯随机绕过复习计划 |
| FR-516 | 每题带元数据：目标音名、标准位置（弦/品）、所属训练项键、来源标签（新题 / 到期复习 / 薄弱强化 / 错题回炉） |

#### FR-520 谱面呈现

- 六线谱：6 条水平线，自上而下对应 1–6 弦（最上为高音 E 弦，符合通用惯例）。
- 在标准位置画品格数字；弦线上方标注弦序号（可关）。
- 全屏大字模式：谱面占屏幕 ≥ 60% 高度，品格数字字号随窗口自适应放大。
- 来源标签以小字显示在角落（如"复习"），不干扰读谱。

#### FR-530 判定引擎

| 编号 | 需求 |
|---|---|
| FR-531 | 判定对象为**音名（pitch class）**，与八度、弦、品无关 |
| FR-532 | 音准容差：滑块可调 **±10 ~ ±50 音分**，默认 **±25 音分**，步进 5 |
| FR-533 | 稳定时长采用**三档预设**（可在设置中切换，默认**平衡**）：<br>① **快速 150ms** —— 端到端约 243ms，适合安静环境、追求即时反馈<br>② **平衡 200ms**（默认）—— 端到端约 283ms，满足 NFR §4.3 的 ≤300ms 目标<br>③ **稳健 300ms** —— 端到端约 383ms，适合噪声较大或手不稳的环境<br>高级设置中仍可自定义 150 ~ 600 ms（步进 50） |
| FR-533a | 稳定性判定采用**滑动窗口多数表决**，而非"连续 N 帧全合格"：在最近 N 帧（N = 稳定时长 / 帧移）内，若某音名的有效帧占比 ≥ 70% 即判定。实测"连续帧"方案在 20dB 噪声下会全部失败，多数表决则为 7/7（见技术方案 §6.7） |
| FR-533b | 单帧置信度下限 0.80：低于此值的帧不计入有效帧（用于拦掉低音区窗口不足时的错误解） |
| FR-534 | 宽容期：默认 **2.0 s**（可调 0 ~ 5 s），期内检测到的音只用于实时显示，不判对错 |
| FR-535 | 试音处理模式（**三个模式都提供，用户可选**【已定】）：<br>① **宽容期模式**（默认）：期内试音不判错，期后取第一个稳定音为答案<br>② **严格模式**：立即取第一个稳定音为答案，试音会被判错<br>③ **宽容模式**：全程不判错，只记录"弹对所用时长" |
| FR-536 | 无声音超时：默认 **8 s**（可调 3 ~ 30 s），超时记为"未作答/不会"，计入薄弱项，并自动出下一题 |
| FR-537 | 答错处理【已定】：**提示错误并停留当前题，直到弹对**；谱面高亮标准位置；错几次记几次（用于熟练度与统计） |
| FR-538 | 判定必须包含**谐波校验**：若检测频率 f 的 2f/3f 谐波能量显著，且 f 处于低音区，优先采用谐波关系修正后的基频，抑制八度误判 |
| FR-539 | 低于置信度阈值的检测结果不参与判定（噪声不冤判） |
| FR-540 | 判定结果须附带：是否正确、检测到的音名与频率、音分偏差、反应时间（从宽容期结束/首次有效音起算）、尝试次数 |

#### FR-541 反应时间的定义（关键，影响统计口径）

- **计时起点**：题目渲染完成并在屏幕上可见的时刻。
- **计时终点**：判定为正确那一刻。
- 严格模式下起点为出题瞬间；宽容期模式下试音不重置时钟（否则会鼓励拖延）。
- 反应时间超时不计入平均（另计"未作答次数"）。

### FR-600 记忆曲线与易错强化【已定】

#### FR-610 训练项与熟练度

- **训练项键 = 音名 × 把位区间**（例：`B@L2`），由"目标音名 + 题目所属把位区间"确定。
- 每个训练项记录：`ease`（难度因子）、`interval_index`（间隔档位）、`due_at`（下次到期时间）、`reps`（累计正确次数）、`lapses`（遗忘/答错次数）、`error_rate`（滚动错误率）、`avg_rt_ms`（滚动平均反应时间）、`last_seen_at`。
- 采用 **简化 SM-2 间隔重复 + 易错加权**：

| 事件 | 处理 |
|---|---|
| 答对（首次尝试即对，宽容期模式下视为首次稳定音即正确） | `interval_index += 1`，`due_at = now + 间隔[interval_index]` |
| 答错（含多次尝试后答对） | `interval_index = 0`，`due_at = now + 间隔[0]`（当天重现），`lapses += 1` |
| 跳过 / 超时 | 同"答错"，但 `lapses` 权重减半 |
| 带提示答对（开启了音名提示） | 不计入熟练度提升，仅记录 |

**间隔序列**：`[0（当天内回炉）, 1天, 3天, 7天, 16天, 35天, 75天, 160天]`（最后一级封顶 160 天）。

#### FR-620 难度进阶建议【已定】

- 触发条件（对当前把位区间，取**最近 3 次会话**）：正确率 ≥ 90% 且平均反应时间 ≤ 2.5 s 且累计答题数 ≥ 60。
- 表现：首页对应模块卡片出现"建议解锁下一难度（L2: 0–5品）"提示，点击进入确认。
- **不自动切换**，必须用户确认。

#### FR-630 跨范围复习策略【已定：不跨界】

- 到期复习项**只在当前选定把位区间内**产生。超出当前范围的高难度到期项保持"积压"状态，不强行出题。
- 缩小学练范围时不做任何数据惩罚；扩大范围时，积压的到期项按到期时间先后优先复习。
- 设置中**不提供**"允许跨难度复习"开关（保持简单；未来若需要再作为新功能评估）。

### FR-700 出题调度【已定】

#### FR-710 三种来源与配比

每 **10 题**为一个配额窗口，按以下优先级填充：

| 来源 | 每 10 题配额 | 说明 |
|---|---|---|
| ① 到期复习 | ≤ 4 题 | `due_at <= now` 的训练项，逾期越久优先级越高 |
| ② 薄弱项强化 | ≤ 3 题 | 未到期但错误率高/反应慢的训练项，加权随机 |
| ③ 新题 | ≥ 3 题 | 当前范围内尚未建立或熟练度低的训练项 |

实际数量按可用项动态调整：某类无可用项时，其配额顺延给下一类；全部训练项都已熟练掌握时，允许出现"到期项为 0、新题为主"的正常状态。

**薄弱项权重公式（草案）**：

```
w = (1 + 2.0 × error_rate)                 # 错误率权重
  × (1 + 1.5 × max(0, (target_rt - avg_rt) / target_rt))   # 慢反应权重，target_rt 默认 2500ms
  × (0.5 + 0.5 × min(1, 距上次练习天数 / 7))  # 时间衰减：越久没练越该练
```

按 `w` 做加权随机抽取。

#### FR-720 错题回炉【已定】

- 本次会话中答错/跳过/超时的题，**间隔 5 ~ 8 题（随机）后重新出现**。
- 回炉题带"回炉"标签，仍按正常判定。
- 同一题连续 **2 次**答对后移出回炉队列；再次答错则重置回炉计数并重新排期。
- 回炉题不占用 FR-710 的配额窗口（额外叠加），但单次会话回炉题总量不超过总题量的 30%，避免刷同一题。

#### FR-730 会话内实现要求

- 调度器须可**确定性重放**（给定随机种子与历史，出题序列可复现），以便测试与问题定位。

#### FR-830 得分与连击【已定，可关闭】

```
得分 = 100（基础分）
     × 难度系数（L1 1.0 / L2 1.2 / L3 1.4 / L4 1.6）
     × 时间奖励（≤1.5s ×1.5 | ≤3s ×1.2 | ≤5s ×1.0 | 其他 ×0.8）
```

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 低音 E2（82.41Hz）检测不准 | 低音弦题目频繁误判，用户弃用 | 检测窗 ≥2048 点；谐波校验；界面以"收音中"状态明示延迟；低音区单独回归测试 |
| 八度误判（E2 听成 E3） | 判定错误 → 信任崩塌 | 谐波能量比校验 + 置信度门限；因判定只认音名，八度误判**不影响对错结论**（天然免疫），但仍影响实时音高显示，故仍需校验 |
| 环境噪声 / 邻居声音触发判定 | 无辜判错 | 首次噪声测量 + 起音门限 + 稳定时长 + 置信度三重过滤 |
| 试音被当作答案 | 挫败感 | 默认宽容期模式（FR-535） |
| 泛音、扫弦、闷音干扰 | 误判 | 起音检测（attack）+ 基频清晰度（aperiodicity）门限；无清晰基频时不予判定 |
| PyInstaller 打包音频库失败 | 无法交付绿色版 | 早期（M1）即验证 sounddevice + PortAudio 的打包，不留到最后 |
| PySide6 打包体积过大 | 超过 300MB 目标 | 排除无用 Qt 模块（QtWebEngine、Qt3D 等），build 脚本显式 include/exclude 清单 |
| 麦克风被其他程序独占 | 无法采集 | 设备枚举 + 明确错误提示 + 允许切换设备；推荐 Windows 共享模式设置说明 |
| 桌面采样率不支持 48kHz | 采集失败 | 回退到设备默认采样率，检测算法按实际采样率自适应 |

## 10. 验收标准（可测试）

1. 解压绿色版到任意目录（含中文路径、含空格路径），双击 exe 可正常启动，无需管理员权限。
2. 首次运行向导可完成设备选择、噪声测量、六弦校准，全程无报错。
3. 调音器能正确识别六根空弦，音分偏差显示与实测偏差误差 ≤ ±5 音分。
4. 练习屏在 1920×1080 下，1 米外可清晰读出六线谱上的品格数字。
5. 弹出正确音名（任意弦、任意八度）→ 判定通过；弹出错误音名 → 判定失败并显示"你弹的是 X，需要 Y"。
6. 在 ±25 音分内但持续不足 300ms 的音，不判为正确（无误判）。
7. 出题后 2 秒内试弹任意音不判错（默认宽容期模式）。
8. 三种会话模式（固定时长/固定数量/自由）均能按定义正确结束，并生成小结。
9. 暂停/继续/跳过/超时/手动结束/快捷键全部有效，数据一致（进度与实际相符）。
10. 答错项在 5~8 题后按规则回炉；连续 2 次答对后不再回炉。
11. 到期复习项按 FR-710 配比出现；当前范围外的到期项不出题（不跨界）。

| 5 | A2 | 45 | 110.00 | A A# B C C# D D# E F F# G G# A |

| 3 | G3 | 55 | 196.00 | G G# A A# B C C# D D# E F F# G |

### C. 明确不做的判定幻想（写入用户手册）

> 本程序通过麦克风判断**音高**，无法知道你按的是哪根弦、哪个品。因此当题目标注"第 5 弦第 2 品"时，你在别的弦上弹出同样的音也算通过。标注位置的作用是帮你建立指板地图，而不是限制你必须按在那里。
